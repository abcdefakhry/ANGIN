# ANGIN (Anggaran Indonesia)

### Tagline: "Dari Pajakmu, Jadi Apa untuk Kotamu?"
### Kompetisi: Web In Action (WIA) – Multimedia In Action 2026 (UPN Veteran Jakarta)
### Subtema: Open Government Data



## Struktur Proyek

```
ANGIN/
├── src/
│   ├── App.tsx
│   ├── main.tsx
│   └── index.css
├── index.html
├── package.json
├── tailwind.config.js
├── tsconfig.json
└── vite.config.ts
```

## Cara Menjalankan

### 1. Instalasi Dependensi
```bash
npm install
```

### 2. Menjalankan Server Development
```bash
npm run dev
```
Akses di browser: `http://localhost:5173`.

### 3. Build Produksi
```bash
npm run build
```

### 4. Preview Build Produksi
```bash
npm run preview
```
